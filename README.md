# The Great Indian Table

A visual archive of everyday workspaces and the people behind them.

## Project

This repository contains the complete static website codebase, including the map, table records, gallery, story views, Add Your Desk form, styles, scripts, and image assets.

## Run locally

Serve the project with any static HTTP server. For example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/index.html`.
